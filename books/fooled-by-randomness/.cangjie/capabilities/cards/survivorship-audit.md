# 存活者偏差审计（数一数打字机前的猴子）

## R — 原文 (Reading)

> 在输赢概率各半的游戏中，我们现在有313位经理人连续5年获利。这纯粹是靠运气得来的。
>
> — 塔勒布，《随机漫步的傻瓜》第9章

> 换句话说，如果不知道曾有多少经理人尝试过且失败，我们没办法评估绩效记录的有效性。要是原始群体只有10个经理人，那么我会毫不考虑地把一半的积蓄交给表现优异者。如果原始群体有一万名经理人，我会对他们的操作成果视而不见。
>
> — 塔勒布，《随机漫步的傻瓜》第9章

> 如何进行合适的仿真？比方说，可以找5年前负责操盘工作的一群经理人，然后进行仿真，直到今天。
>
> — 塔勒布，《随机漫步的傻瓜》第8章

## I — 方法论骨架 (Interpretation)

看到一个"赢家"（明星基金经理、成功人士、灵验的规则、满屏好评），先别问他做对了什么，先问：同一时期一共有多少人、多少规则在试？纯靠运气能冒出多少个这样的赢家？
一段好记录值多少钱，取决于两件事：这一行的随机成分有多大（每一期的成败是否接近抛硬币），以及参与者有多少（多少只猴子在打字）。
**纯运气基准**：N 个毫无本事的参与者，每期成功概率 p，一次失败就出局，连续成功 k 期的期望人数约为 **N × p^k**。如果现实里的明星数量没有明显超出这个基准，那份记录就不构成能力证据。
然后审计样本本身：
- 失败者是否从样本里消失了（清盘的基金、倒闭的公司、放弃的人）？
- 你看到的是否是展示方挑过的"最好的那部分"（推荐语、精选好评、最好看的区间）？
- 样本是否碰巧来自一个特殊时期（如长期大牛市）——赢家样本加特殊时期，就是"双重存活者偏差"？
- 那条规则是不是从大量尝试、反复调参里挑出来的？
修正办法：从过去某一时点的**全体**出发追踪到今天，把退出者算进去；拿不到全体名单时，给区间估计并打折。
结论只分"证据强 / 弱 / 无"，永远不下"这确实是能力"的判断。

## A1 — 书中的应用 (Past Application)

### 案例 1：一万名经理人模拟（313 与 184）
- **材料性质**：例题（作者用蒙特卡罗发生器设定参数的模拟，原书说用硬币或简单代数也可）
- **问题**：一群完全没本事、甚至注定亏钱的经理人，几年后会产生多少"连胜明星"？
- **方法论的使用**：N = 10000，每年赚或赔 1 万美元，一年表现差即淘汰。复算如下（公式 N×p^k）：

| 年份 k | p = 0.5：N×p^k | 原书 | p = 0.45：N×p^k | 原书 |
|---|---|---|---|---|
| 1 | 5000 | 5000 | 4500 | 4500 |
| 2 | 2500 | 2500 | 2025 | 2025 |
| 3 | 1250 | 1250 | 911.25 | 911 |
| 4 | 625 | 625 | 410.06 | 410 |
| 5 | 312.5 | 313 | 184.53 | 184 |

  复算结论：两组数字与原书一致。差异只在取整：312.5 原书取 313；184.53 直接四舍五入为 185，原书为 184（原书逐年取整，第 4 年取 410，410×0.45 = 184.5 再取 184），相差 1 人，不影响结论。占原始群体比例：3.13%（原书"约3%"）与 1.85%（原书"2%以下"）。p = 0.45 时每回合期望为 0.45×1 万 − 0.55×1 万 = −1000 美元（与原书"平均每回合赔1000美元"一致）。
- **结论**：①一群整体能力欠佳的经理人，仍会有少数人绩效记录很好；②明星的数量主要取决于入行人数和市场波动，而不是个人能力。
- **结果**：即上表的模拟结果。作者另讲了一件亲历的事：他对一位"宇内高手"说绩效记录没那么重要，对方拿打火机掷他；该部门 1994 年炸毁，6 年后无一人仍在交易。

### 案例 2："罗宾汉"策略研究——样本里没有退出者
- **材料性质**：转述（作者批评的一项真实研究，未点名）
- **问题**：一位基金界"大师"算出，把钱从表现好的经理人撤出、投给表现差的，回报更高。
- **方法论的使用**：作者指出样本只含"至今仍在操盘"的经理人；持续差的人早已出局，留在样本里的"差经理"都是后来变好的，结论被存活者偏差污染。
- **结论**：正确做法是找 5 年前在操盘的全体经理人，一路模拟到今天。
- **结果**：原书未说明该研究的后续。

### 案例 3：《邻家的百万富翁》的双重存活者偏差
- **材料性质**：转述（作者对一本真实畅销书的批评）
- **问题**：研究现有富人得出"节俭、延后消费能致富"。
- **方法论的使用**：第一重——只研究赢家，没算同样节俭却攒错东西（贬值货币、破产公司股票）的人；作者给的粗略矫正是把富翁平均财富"打个对折"。第二重——样本形成于 1982 年起的大牛市（1982 年的 1 美元股票约涨 20 倍），若书写于 1982 或 1935 年，内容"绝对不一样"。
- **结论**：成功者特质研究必须同时审计"只含赢家"和"特殊时期"两层。
- **结果**：原书未说明该书结论如何被修正；作者以自己祖父买黎巴嫩里拉国库券、曾祖父买沙俄债券为反面设想。

### 合成演练（非原书）
- **输入**：某平台"年度十佳基金经理"榜单，前十名都连续 3 年跑赢大盘，全市场约 3000 名经理。（来自 verified.md v06 演练）
- **执行**：p = 0.5（跑赢/跑输二分，约定），k = 3 → 3000 × 0.5³ = 3000 × 0.125 = **375** 人。M = 10 < 375，十佳完全可由运气产生。再审计：榜单是否只含仍在任者？统计区间是否恰逢某风格行情？
- **输出**：证据等级"无"——榜单不构成能力证据；待查：全市场含离任者的名单、区间行情。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要

1. **投资**：看到"连续 N 年跑赢""冠军基金""十佳经理"榜单，或想跟某位明星经理、带单交易员、荐股人。
2. **投资**：评估回测结果、量化策略、"屡试不爽"的技术指标、"长期持有股市必涨"类结论。
3. **职业选择**：因为某行业"成功的人很多"或某位成功人士的经验而想入行、转行、创业。
4. **日常决策**：读成功学、名人传记、"富人习惯"研究；凭书封推荐语、精选好评、学员成功案例做选择。
5. **审阅研究/报告**：数据库是否只含现存对象、研究时段是否特殊、试过多少版本才得出结论。

### 语言信号

- "连续 X 年跑赢""年度冠军""十佳""常胜""他做到了，你也可以"
- "成功人士都有这些习惯""回测年化 X%""这个指标屡试不爽""长期来看股市总是涨的"
- "我身边炒股赚钱的人很多""这个专业毕业生收入都很高"
- English: "survivorship bias", "track record", "top performers", "star fund manager", "outperformed N years in a row", "backtest", "data mining", "overfitting", "success stories", "silent evidence"

### 与相邻能力的区分

- 与 `luck-vs-skill` 的区别：`luck-vs-skill` 做整体归因（含过程证据、非线性赢家通吃）；本卡专门做"群体有多大、样本漏了谁"的计算与审计，可作为它的子步骤。
- 与 `adverse-selection` 的区别：业绩是对方**主动推送**给你的，先用 `adverse-selection`；本卡处理一般的榜单、研究、成功案例。
- 与 `probability-blindness` 的区别：单个巧合（生日相同、偶遇）、基础率与条件概率问题交给 `probability-blindness`；本卡针对"从群体中筛出赢家"的结构。

## E — 可执行步骤 (Execution)

### 输入契约

| 字段 | 必需 | 类型/单位 | 说明 |
|---|---|---|---|
| 审计对象 | 是 | 文本 | 哪个赢家/榜单/规则/结论，其"成绩"如何描述 |
| 成功定义与 k | 是 | 整数（期） | 每期"成功"指什么，连续多少期 |
| N | 是 | 人数/家数/规则数 | 同期参与者总数；不确定时请用户给低、高两个估计 |
| p | 是 | 0–1 | 单期纯运气成功概率；见下方约定 |
| M | 否 | 人数 | 现实中观察到的同等记录者数量 |
| 样本信息 | 否 | 文本 | 数据是否含退出者、统计时期、展示方是谁、试过多少版本 |

- 缺 N 时先问，不替用户编数字；可提示去哪找（基金总数、从业人数、规则尝试次数）。用户也给不出时，只做第 4 步样本审计，结论最高为"弱"。
- p 的约定（非原文）：成功定义为"跑赢/跑输""赚/赔"二分时，取 p = 0.5（与原书 50/50 设定一致）；定义为"排名前 x%"时取 p = x%；用户有更好的估计则用用户的。所用 p 必须在输出里写明来源。

### 输出契约

1. 纯运气基准表：N、p、k、逐期 N×p^i（i = 1…k）、最终 B = N×p^k（保留 1 位小数，并给四舍五入整数）；N 为区间时给低/高两列
2. 对比：M 与 B
3. 样本审计四问（A 退出者 / B 挑选展示 / C 特殊时期 / D 多重尝试）：是 / 否 / 未知 + 依据
4. 证据等级：强 / 弱 / 无（只有这三档）
5. 修正建议与待查问题
6. 升级去向
7. 声明：不构成投资建议

### 步骤

1. **界定赢家与参数**
   - 写出："连续 k 期、每期成功定义为……，纯运气 p = ……（来源：用户/约定）"。
   - 完成标准：k、p、N（或区间）全部有值且有来源。
   - 跳转：如果成功不是"一次失败即出局"的连胜（例如"5 年中有 4 年跑赢"），N×p^k 不适用，改用二项分布 N×P(成功次数 ≥ j)，并注明"超出原书口径（约定）"。

2. **计算纯运气基准**
   - 公式：B = N × p^k。计算顺序：逐期计算 N×p、N×p²……N×p^k 并列表（便于核对，与原书逐年列数一致）；最终值用直接公式计算，保留 1 位小数，再四舍五入为整数（约定）。与原书逐年取整的结果可能差 1 左右，属取整误差。
   - 完成标准：表格可复算；N 为区间时两端都算。

3. **对比并初定证据等级**（门槛为约定，参照原书"10 人愿托付一半积蓄、1 万人视而不见"）
   - B ≥ 1：仅靠运气就预期出现至少 1 个同等赢家 → 记录本身**不构成证据**，初定"无"。
   - B < 1：运气难以单独产生该记录 → 初定"强"候选（原书 10 人群体时 10×0.5⁵ ≈ 0.3，作者愿托付一半积蓄）。
   - 有 M 时一并写出 M 与 B 的比较（M ≤ B 说明明星数完全在运气范围内）。
   - 完成标准：给出初定等级与一句理由。

4. **样本审计四问**
   - A 退出者：数据/名单是否只含仍存在的对象（清盘基金、离职经理、倒闭公司、放弃者被剔除）？
   - B 挑选展示：看到的是否是展示方挑出的最好部分（最好的产品、最好的区间、最好的评语）——是"极大值的分布"而不是全体？
   - C 特殊时期：样本是否来自某类资产的长期牛市、行业红利期、单一国家？
   - D 多重尝试：规则/结论是否经反复调参、在大量候选里挑出？一共试了多少次？
   - 降档规则（约定）：任一项为"是" → 等级最高为"弱"；两项及以上为"是" → "无"。"未知"不降档，但必须列入待查问题。
   - 完成标准：四问都有答案和依据，最终等级唯一。

5. **修正与输出**
   - 修正方法：①回溯法——从过去某一时点的全体出发追踪到今天，退出者计入（原书第8章做法）；②把规则尝试次数计入 N；③换时期、换市场做反事实（"如果是 1935 年/别的国家"）；④成功学结论粗略打折（原书"打个对折"只是示例性修正，不是精确方法）。
   - 待查问题：全体名单从哪拿、退出者有多少、统计区间与行情、试过多少版本。
   - 升级：需要过程证据和整体归因 → `luck-vs-skill`；业绩是推销上门的 → `adverse-selection`；业绩曲线异常平滑 → `hidden-tail-risk`；要决定是否下注 → `expected-value` / `ruin-first`。
   - 完成标准：输出契约 1–7 项齐全。

## B — 边界 (Boundary)

### 不适用场景
- 单个巧合或某个检测结果的可信度（基础率、条件概率）→ `probability-blindness`。
- 已经拿到包含全部退出者、全部时期的完整数据：存活者偏差已被处理，本卡只需复核，不必重算。
- 用户要"该买哪只基金/跟哪位老师"：本卡只评估记录的证据强度，**一律不提供具体买卖建议**，不替代专业财务意见。

### 作者警告的失败模式
- 只看赢家，不数猴子；数据越多越自信（"只懂少许概率知识比完全不懂概率的结局更惨"）。
- 只含存活者的回测（罗宾汉策略）；把"最好的书评"当"书评"。
- 在规则中找存活者：调参调到满意为止，在数据压力下丧失怀疑。
- 把单一国家、单一时期的长期回报（"任何20年都只涨不跌"）当普遍规律。

### 作者盲点与缺口
- **原始群体规模常不可得**（verified.md v06 gaps）：只能给区间估计，结论随之变弱，不能为了出数字而硬填 N。
- N×p^k 假设各期独立、一败即出局。现实中同风格的人会一起赢一起输（风格行情），这时纯运气产生的明星可能更多，基准会低估运气。
- 作者承认答不上"何时才是真的不靠运气"（needs-review N3 同源）：本卡只输出"证据强/弱/无"，**不输出"是能力"**；"强"也只表示记录层面难以用运气解释。
- "打对折"无推导依据；p = 0.5 等默认值是约定。
- 作者自己的论证也大量依赖精选故事（虚构的塔利波稳健、约翰炸毁），同样是单一路径样本。照做过头会让人对小群体里的真高手也一概不信——原书本身就承认群体只有 10 人时记录有分量。

### 与相邻能力的混淆点
- 本卡回答"有多少可能是运气筛出来的"，`luck-vs-skill` 回答"综合来看有多少是运气"；`adverse-selection` 额外处理"谁选择让你看到"。
