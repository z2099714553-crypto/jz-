# 先问失败能否承受：毁灭风险优先与防炸毁纪律

## R — 原文 (Reading)

> 梭伦甚至了解另一个相关的问题，我把它叫做偏态；如果失败的代价过于沉重、难以承受，那么这件事成功的概率有多高根本无关紧要。
>
> — 塔勒布，《随机漫步的傻瓜》第一篇引子

> “炸毁”有个明确的意义，指的不只是赔钱，而且是损失金额超过预期，以致在这一行再也待不下去，就如医生失去行医执照或律师被取消资格。
>
> — 塔勒布，《随机漫步的傻瓜》第一章

> 每当损失到一定的程度时，塔利波会马上结束交易。他从来不卖“未抵押期权”（一种操作策略，有可能发生很大的损失），不管概率有多小，他从来不让自己落到可能损失比方说100万美元的状况，赔钱的上限会视他当年累积的利润多寡而做调整。
>
> — 塔勒布，《随机漫步的傻瓜》第一章

## I — 方法论骨架 (Interpretation)

做任何有风险的事之前，第一个问题不是"成功概率多大""能赚多少"，而是"最坏情况下我还在不在场上"。
要区分两种损失：普通的亏损（疼，但能继续玩）和"炸毁"（亏得超出预期，直接出局、无法翻身，比如清零、负债、失去执照或职业）。
如果某个选项里存在炸毁的可能，而且这个代价承受不起，那么它成功的概率再高也不应该做，或者必须先改到承受得起为止。
理由是：只玩一次也许没事，但人一生会反复面对同类选择；反复玩带"子弹"的转盘，坏历史迟早会轮到你。
落地纪律有四条：事先定好亏损上限、到线就退；不碰"可能产生巨额损失"的结构（不论概率多小）；把赖以生存的积蓄和用来冒险的钱分开；对杠杆格外小心，因为它会把小跌变成清零。
另外两个常见陷阱：说"这次不一样""我和别人不同"，拒绝用别人的经验估计自己的风险；以及只在专业领域守纪律，生活里的风险却不管。

## A1 — 书中的应用 (Past Application)

### 案例 1: 塔利波的保守交易（虚构人物）
- **材料性质**: 尼罗·塔利波是作者虚构的人物，第一章
- **问题**: 怎样才能"在这一行长命百岁"，而不是追求利润最大？
- **方法论的使用**: 亏到一定程度立刻平仓；从不卖未抵押期权；亏损上限随当年累计利润调整；个人积蓄只放最安全的工具（公债），只赚现金收入、不靠投资致富。
- **结论**: 代价是赚得比"宇内高手"少、错过了大牛市；换来的是不会出局。
- **结果**: 书中情节：1994 年债市崩跌，争取绩效的同行集体炸毁，他安然无恙（虚构情节）

### 案例 2: 约翰的炸毁——杠杆与"10 西格玛"（虚构人物）
- **材料性质**: 约翰是作者虚构的人物（塔利波的对照），第五章续写其结局
- **问题**: 赚钱多年、看起来有对冲保护的高收益债券交易员，风险在哪里？
- **方法论的使用**（反例）: 约翰把个人近 1400 万美元投回业务，并加杠杆维持 5000 万美元组合（其中 3600 万借来）；1998 年夏市场跌幅不大，但持仓同时不利、对冲失灵；他的模型说这种事"100 万亿亿年才有一次"。
- **结论**: 杠杆把小赔滚成清零；"赔钱可以，赔掉超过准备输掉的不行"。
- **结果**: 书中情节：1998 年 9 月约翰被解雇，几乎失去一切（虚构情节）

### 案例 3: 拒斥历史的同行与"这次不一样"（亲历观察）
- **材料性质**: 作者亲历观察与自我坦白，第三章
- **问题**: 为什么炸毁的人总是相似？
- **方法论的使用**: 作者观察 1987 年股灾、1990 年日本股市、1994 年债市、1998 年俄罗斯危机、2000 年纳斯达克中炸毁的人：都说"这次不一样""他们的市场不一样"，拒绝用别人的概率推演自己的风险；作者坦白自己也懒得做体检。
- **结论**: "这次不一样""我与众不同"是炸毁前的红旗；要用参照人群的经验估计自己的风险。
- **结果**: 作者称"就我所知，拒斥历史的所有同行，后来都炸毁得很惨"——修辞性断言，原书未给数据

### 合成演练（非原书）: 首付款加 3 倍杠杆买币
- **问题**: 朋友劝我把首付款加 3 倍杠杆买某币，说胜率 90%
- **方法论的使用**: ①最坏路径：爆仓 → 首付清零、可能负债 → ②能否承受：不能（买房计划终结） → ③判定：不论胜率多高都不做；若坚持参与，只用"亏光也不影响生活"的钱、不加杠杆 → ④重复检查：即便这次赢，反复这样做终会遇到"子弹"
- **结论**: 拒绝，或封顶损失后再考虑
- **结果**: 演练，无真实结果（来源：verified.md v03 演练）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要

1. **投资**: 考虑加杠杆、借钱投资、全仓/梭哈、卖期权或类似"赚小钱、可能赔大钱"的结构；或用应急钱、首付、养老钱去博收益
2. **职业选择**: 面临"一次失败就出局"的赌注——违规操作、全部身家押在一个雇主/客户/项目上、辞职创业且无退路
3. **日常决策**: 做一件高收益但可能造成不可逆伤害的事（健康、安全、法律风险），或因"一直没出事"而放松
4. **财务规划**: 想把储蓄和高风险投资混在一起管理，或问"最多可以亏多少"
5. **专业外的风险**: 在本行很谨慎，却在生活中做高风险选择（作者以虚构人物塔利波驾驶直升机坠毁为例）

### 语言信号

- "胜率很高，应该没问题吧？" / "the odds are in my favor"
- "加点杠杆赚得更快" / "leverage", "margin", "all-in", "YOLO"
- "这次不一样" / "this time is different"
- "一直都没出过事" / "it has never happened before"
- "最坏会怎样？能不能承受？" / "worst case", "risk of ruin", "can I afford to lose this"

### 与相邻能力的区分

- 与 `expected-value` 的区别：`expected-value` 算"平均下来赚不赚"；本卡先于它把关"最坏一条能不能活"。期望值为正也不能抵消不可承受的毁灭风险。
- 与 `hidden-tail-risk` 的区别：后者负责把"稳定高收益"背后看不见的尾部找出来；找到之后"能否承受、怎么封顶"由本卡处理。
- 与 `falsify-and-stop` 的区别：后者为单笔下注写止损和证伪条件；本卡确定整体的出局底线与仓位上限，止损必须服从本卡的上限。

## E — 可执行步骤 (Execution)

**输入契约**（缺任何一项先问用户，不猜值）：
- 要做的事/下注结构（含是否用杠杆、借款、期权或担保）
- 投入的金额或资源，以及它在用户总资产/收入中的占比
- 资金/资源的用途属性：是否为积蓄、应急金、首付、养老金等生存性资金
- 用户自定的"不可承受线"：亏到多少、失去什么就会出局（**必须由用户给出**，本卡不替用户定）
- 这类选择是一次性还是会反复做

**输出契约**：
- 最坏路径描述（含路径途中最低点，而非只看终点）
- 判定：可承受 / 不可承受 / 信息不足
- 若可做：亏损上限（金额）、退出条件、资金隔离方式、杠杆限制
- 若不可做：明确说"不做"或"改到可承受后再议"，并说明改法方向

**步骤**：

1. **写最坏路径**
   - 做法: 写出该选项最坏的 1–3 条路径，包括杠杆、追加保证金、连带责任、流动性枯竭等放大因素；参照同类人群的历史经验，不接受"这次不一样""我不一样"作为排除理由
   - 完成标准: 每条最坏路径都有具体后果（金额或失去的东西）

2. **对照不可承受线**
   - 做法: 把最坏路径的后果与用户自定的不可承受线比较
   - 完成标准: 给出"越线/不越线"判定
   - 判停: 若用户无法给出不可承受线，停在此步，先帮用户界定（列出其生存性资金与不可失去的东西），不得自行假设
   - 跳转: 若越线 → 步骤 3；若不越线 → 步骤 4

3. **越线处理**
   - 做法: 结论默认为"不做"，不论成功概率多高；若用户坚持参与，只能改结构直到最坏结果不越线：去掉杠杆、缩小规模到"亏光也不影响生活"、避开可能无限亏损的结构
   - 完成标准: 输出"不做"，或一份改后结构，且改后最坏结果已重新对照步骤 2 判为不越线

4. **设纪律**
   - 做法: 写下亏损上限与到线即退的规则；亏损上限可随已实现利润调整（原文做法）；生存性资金与冒险资金分账；明确杠杆上限
   - 完成标准: 四项（上限、退出条件、资金隔离、杠杆限制）都有明确数值或规则

5. **重复博弈检查**
   - 做法: 问"如果每年都这样做一次，十年后会怎样？"——带有任何出局可能的选择，反复做的累积出局概率会越来越高
   - 完成标准: 写出一句"反复做"情境下的结论；若用户在专业外也有类似高风险习惯，一并提示

## B — 边界 (Boundary)

### 不适用场景
- 最坏结果明显可承受、可逆的小额尝试（试错成本低时，过度防御会错过机会）
- 没有任何下行的纯选择（例如两份无风险的选项比较），转 `coin-flip-deadlock` 或 `expected-value`
- 心理危机、人身安全紧急情况：应立即寻求专业帮助，而非套用本卡

### 作者警告的失败模式
- 只看胜率不看代价："成功的概率有多高根本无关紧要"
- 多次侥幸后忘了子弹，越久没出事越大意
- 杠杆把小跌变成清零
- "这次不一样""我与众不同"、以为大事来临时自己会事先知道
- 懂概率不等于做得到：凯恩斯写过《概率论》，操作自己账户仍炸毁（转述）
- 专业里谨慎、生活中失明（塔利波驾直升机坠毁，虚构情节）

### 作者盲点（来自阶段 0 批判）
- 止损可执行的前提，与作者自己描述的稀有事件中"平仓踩踏、价格跳空"相矛盾：到线即退在极端行情下可能无法按价执行，因此本卡要求以"仓位/杠杆上限"为主、止损为辅（参见 needs-review N4，主属 `falsify-and-stop`）
- 作者的论证多依赖虚构人物（塔利波、约翰），"拒斥历史的同行都炸毁了"无数据
- 过度防御的代价作者未计算：一律回避不确定性可能错过真实机会

### needs-review / verified 相关缺口
- verified.md v03 无缺口；"不可承受"的线必须由用户自定，本卡不替用户设数值
- 亏损上限、杠杆上限的具体数值原书未规定，由用户按自身情况设定

### 与相邻能力的混淆点
- 与 `expected-value`：期望值为正不能推翻本卡的"不做"
- 与 `falsify-and-stop`：止损是本卡纪律的一部分工具，但不能替代仓位上限

### 声明
本卡不提供任何具体的买卖、杠杆或投资产品建议，不替代专业财务、法律、医疗或心理意见。
