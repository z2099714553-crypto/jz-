# "稳定高收益"的隐藏尾部风险诊断（比索问题 / 在铁轨上打盹）

## R — 原文 (Reading)

> 参与高收益市场，就好比在铁轨上打盹，终有一天下午，突如其来的火车会撞死你。一段很长的时间内，你可能每个月都赚钱，然后在短短几个小时内，赔掉历年来累积利润的好几倍。
>
> — 塔勒布，《随机漫步的傻瓜》第1章

> 我不厌其详，说明这个观念已经普遍化，任何一种投资形式，只要是以天真幼稚的态度解读以前时间序列的波动性，都适用这个观念。
>
> — 塔勒布，《随机漫步的傻瓜》第6章

> 如果去看更宽广的历史，我们会发现，某个地方从来没有发生的事，最后往往会发生。换句话说，历史告诉我们，以前从未发生的事，后来竟然发生了。
>
> — 塔勒布，《随机漫步的傻瓜》第6章

## I — 方法论骨架 (Interpretation)

一条收益曲线越平滑、越"从来不亏"，越要追问：亏损是真的没有，还是被攒到了某一天一起来？
很多赚钱方式的结构是"常赚小钱、偶尔赔大钱"：替别人承担罕见大损失（卖保险、卖价外期权）、借低息投高息赚利差、加杠杆、越跌越买。
这种结构平时的记录又稳又好看，风险全部藏在还没发生的那一天——像在铁轨上打盹，火车来之前每天都很舒服。
诊断分三层：
1. **症状**：长期低波动、收益明显高于无风险利率、很少或没有亏损期，并且"一直没出事"被当作主要理由。
2. **判断**：钱从哪里来？看的历史够不够宽（别的国家、别的年代、同类策略出过事没有）？报告里有没有把"那一次"当异常值删掉？危机时对冲和分散会不会一起失灵（所有人同时夺门而逃）？产生数据的环境是不是已经变了？
3. **处置**：没弄清楚之前，按"可能一次赔掉多年利润甚至本金"对待——不加杠杆，只放亏光也承受得起的钱，或者不碰。
两个关键心态：稀有事件按定义就是出乎意料，"无法预见"不是借口；吸取一个教训时，要排查所有同结构的东西，而不是只避开出过事的那一个品种。

## A1 — 书中的应用 (Past Application)

### 案例 1：约翰——在铁轨上打盹
- **材料性质**：作者虚构的人物（第1章出场，第5章续写结局），不是真实事件
- **问题**：约翰做高收益债券利差交易（借 5.5% 的钱买收益率 10% 的债券），用公债期货"避险"，加杠杆；营业收入年年约翻倍，35 岁身家超过 1600 万美元，又把近 1400 万投回业务。
- **方法论的使用**：邻居塔利波（同为作者虚构的人物）判断：约翰的稳定收益是"赚小钱、赔大钱"的结构；他市场经验太少、不研究历史，看不到自己承担的炸毁风险。
- **结论**：稳定本身就是风险的表现，而不是能力或安全的证明。
- **结果**（虚构情节）：1998 年夏市场跌幅不大，但他几乎所有持仓同时不利、避险失灵、杠杆过大；风控模型称此事"100 万亿亿年才有一次"（"10 西格玛"）。几天内 1400 万美元化为乌有、丢掉工作，剩约 100 万；7 年为雇主赚约 2.5 亿美元，几天赔掉最后一位雇主 6 亿美元以上。

### 案例 2："我们不碰墨西哥比索，只投资俄罗斯卢布"
- **材料性质**：作者亲历（1998 年春与一位重量级避险基金经营者的谈话）
- **问题**：对方是否理解比索问题——高利率、长期平静的货币会"出乎意料"地崩跌。
- **方法论的使用**：作者花两个小时说明：凡以天真态度解读过去波动性的投资都适用这个观念。
- **结论**：对方只听成"别碰比索"，转而持有利率诱人的卢布资产——把一般结构窄化成了一个具体品种。
- **结果**：1998 年夏，他和持有卢布计价资产的人赔了将近 97%，几个月后炸毁。

### 案例 3：预期最糟跌 4%，实际重挫 40%
- **材料性质**：作者概括的典型情境（"许多交易员会……"），非具名事件
- **问题**：一只买进抵押证券、用复杂模型避险、请了一堆理工科博士的基金，长期报酬稳定、几乎不波动。
- **方法论的使用**：稀有事件常由恐慌平仓引发，不限于一种证券，会同时冲击整个组合；"同类基金都这样"不能免责。
- **结论**：稳定收益 + 对冲 ≠ 低风险；"由于无法预见的罕见事件……"正是稀有事件的定义。
- **结果**：示例中组合重挫 40%，而投资人原本预期最糟不过跌 4%。

### 合成演练（非原书）
- **输入**：某私募产品 3 年来每月都是正收益，最大回撤 0.5%，年化 12%。（来自 verified.md v05 演练）
- **执行**：症状命中（平滑 + 高收益 + 无亏损月）→ 判断条件：收益来源是否卖保险/卖期权/高杠杆利差（未说明 = 未排除）；同类策略在更宽历史中（如历次市场危机）有无崩跌（只有 3 年平静期数据 = 未排除）；是否存在流动性/平仓踩踏下同时失灵的风险（未排除）。
- **输出**：定级"未排除（中）"及以上；待查三问交给用户去问销售方；在弄清来源前按"铁轨上打盹"型对待，转 `ruin-first` 确定只投可承受全损的金额。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要

1. **投资**：遇到"每月正收益、几乎无回撤、年化明显高于存款"的理财、私募、基金、策略，或自己的策略多年很稳、正想加仓/加杠杆。
2. **投资**：高息货币、固定汇率资产、"刚兑"高息产品、卖期权/卖波动率、借低投高的利差收益。
3. **职业选择**：收入极稳但依赖单一雇主/客户/政策/渠道；高奖金但承担隐性签字责任的岗位；"从来没裁过员""铁饭碗"的行业。
4. **日常决策**：长期"一直没出事"的冒险习惯（不备份、不买保险、借钱给"一直按时还"的人、长期透支健康）。
5. **复盘/审阅报告**：看到"剔除异常值后""历史最大回撤只有 X%""这种情况百年一遇"之类表述。

### 语言信号

- "每个月都赚""从来没亏过""回撤很小""稳稳的年化 X%""保本高息""已经对冲了"
- "这么多年都没出过事""这种情况几百年一遇""剔除那次特殊情况后"
- "我们不碰 A，只做 B"（换个品种做同一结构）
- English: "steady returns", "never had a losing month", "low volatility", "smooth equity curve", "short vol", "selling options/insurance", "carry trade", "tail risk", "peso problem", "10-sigma event", "picking up pennies in front of a steamroller"

### 与相邻能力的区分

- 与 `ruin-first` 的区别：本卡负责**找出**被藏起来的崩跌路径；找到之后"承受得起吗、怎么封顶"交给 `ruin-first`。
- 与 `expected-value` 的区别：本卡是定性排障（结构是否"常赚小钱、偶亏大钱"）；要把概率×幅度算成期望值时转 `expected-value`。
- 与 `survivorship-audit` 的区别：问"这份漂亮业绩是不是从一大群人里挑出来的"用 `survivorship-audit`；本卡问"这条业绩曲线本身是否藏着尚未出现的亏损"。

## E — 可执行步骤 (Execution)

### 输入契约

| 字段 | 必需 | 说明 |
|---|---|---|
| 对象 | 是 | 产品/策略/收入来源的名称与一句话描述 |
| 收益记录 | 是 | 记录期间长度、年化收益、最大回撤或亏损期数；数据来源；是否剔除过任何时段 |
| 收益机制 | 是（可答"未知"） | 它靠什么赚钱：利差、卖期权/保险、杠杆、单一客户、政策补贴等 |
| 用户暴露 | 是 | 已投/拟投金额及占可用资产比例；是否借钱或用杠杆 |
| 宽历史 | 否 | 同类资产/策略在更长时期、其他市场的表现 |

缺"对象""收益记录""用户暴露"时先问，不猜值。"收益机制"用户答不上来时，不替对方编机制，直接按"未排除"处理。

### 输出契约

一张诊断表，字段固定：
1. 症状 S1–S3：是/否
2. 判断条件 J1–J5：命中 / 未排除 / 已排除，每项附一句依据
3. 定级：高（疑似铁轨上打盹）/ 中（未排除）/ 低（暂未发现）——**永不输出"安全"**
4. 处置动作（与定级对应）
5. 待查问题清单（用户可拿去问销售方或自己查）
6. 同结构排查结果
7. 升级去向及理由
8. 声明：不构成买卖建议

### 步骤

1. **症状筛查**
   - S1 长期低波动、亏损期很少或没有；S2 收益明显高于无风险利率（原书未给量化阈值，由用户与参照利率比较后判断）；S3 "一直没出事/很稳定"是主要卖点或依据。
   - 完成标准：S1–S3 逐项标是/否。
   - 判停：三项全否 → 说明本卡不适用及理由；若用户关心的是一般亏损能否承受，转 `ruin-first`，结束。至少一项为"是" → 进入第 2 步。

2. **逐项判断条件**
   - J1 收益结构：是否"常赚小钱、偶尔赔大钱"（卖保险/卖期权、借低投高、越跌越买、高杠杆、依赖单一对手或政策）。机制说不清 = 未排除。
   - J2 宽历史：同类资产/策略在更长时期、其他国家或市场是否崩跌过？只有一段平静期数据 = 未排除。
   - J3 数据处理：业绩或风险数字是否"剔除异常值/特殊事件"；"最大回撤"基于多长历史。
   - J4 同时失效：危机中对冲、分散、流动性是否会一起失灵（同类投资人同时平仓）。
   - J5 环境是否变过：制度、监管、市场结构是否已改变；所依赖的"规律"是否人尽皆知、会被套利抹平。
   - 完成标准：J1–J5 各有结论和依据；"已排除"必须有具体证据，**"历史上从未发生过"不能作为排除依据**。

3. **定级**（分级规则为约定，非原文；原书未给量化阈值）
   - 高：J1 命中，且 J2–J4 中任一项命中或未排除。
   - 中：J1 未排除；或 J1 已排除但 J2–J5 中有命中。
   - 低：J1–J4 全部已排除，J5 未命中。
   - 完成标准：给出唯一档位，并列出决定档位的条目编号。

4. **处置**
   - 高：按"可能一次赔掉多年利润乃至本金"对待——不加杠杆；只投亏光也不影响生活的金额，或不参与；已持有的，检查是否因"多年没出事"逐年加码或撤掉了防护，若有则说明应回到事先计划的规模（具体如何操作由用户或其持牌顾问决定）。
   - 中：在拿到待查问题答案之前不加仓；列出待查问题：①收益具体从哪里来？②历史上最坏的一天/一个月亏过多少，统计期多长？③是否剔除过任何时段或事件？④同类产品在以往危机中的表现？⑤危机时能否按净值赎回/退出？
   - 低：可进入其他评估，但注明"暂未发现 ≠ 没有"。
   - 所有档位：做**同结构排查**——列出用户其他持仓、收入来源中具有同样结构的项目（卢布案例的教训）。
   - 完成标准：处置动作与档位一致；同结构排查给出清单或写明"未发现同结构项目"。

5. **升级**
   - 存在全损、负债或"一次出局"路径 → `ruin-first`
   - 用户能给出各情境概率与幅度 → `expected-value`（要求概率给区间并做敏感性分析）
   - 业绩来自榜单或从大量产品中挑出 → `survivorship-audit`
   - 产品是对方主动推销来的 → `adverse-selection`
   - 已持有、正在亏损却想继续死守 → `rebuy-test`；准备新下注 → `falsify-and-stop`
   - 涉及具体买卖、税务、法律、合规判断 → 建议咨询持牌专业人士
   - 完成标准：列出升级去向及理由，或写明"无需升级"。

## B — 边界 (Boundary)

### 不适用场景
- 本来就波动大、常亏小钱偶尔大赚的正偏态策略——那是相反的结构，用 `expected-value`、`ruin-first`。
- 结果差距不大的领域（算平均分、规划度假气温），剔除极端值无伤大雅，不必套用本卡。
- 用户只想要"买不买某产品"的结论：本卡只输出风险诊断，**一律不提供具体买卖建议**，不替代专业财务、法律意见。

### 作者警告的失败模式
- 把原则窄化成个案：听懂了"别碰比索"，没听懂"别天真解读平静的历史"，换成卢布照样炸毁。
- 越久没遇到稀有事件越脆弱：因"多年没出事"撤掉防护、加大规模。
- 相信模型说"不可能"："10 西格玛"事件发生了，问题在模型，不在运气。
- 在后果高度不对称的领域剔除离群值。
- 为了少看见波动而选择"偶尔一次巨幅波动"的策略——掩耳盗铃，把随机性塞到地毯底下。

### 作者盲点与缺口
- **N5（needs-review）**："稀有事件被系统性低估"是作者买入价外期权的生意前提，书中没有期权定价实证。因此本卡只给"未排除/疑似"，不断言某产品一定会崩。
- 原书没有量化阈值（多平滑算可疑、多高算"高收益"），第 3 步分级是约定。
- 关键案例约翰是作者虚构的人物，只作示意，不是统计证据。
- 照做过头会把一切稳定收益都当陷阱；判断依据应是**收益来源与宽历史**，而不是"平滑"本身。不过作者也明确说过，"有史以来最为稳定的货币，却最容易崩跌"，所以"有制度保障所以安全"本身也要接受 J5 检查。

### 与相邻能力的混淆点
- 找出隐藏风险 ≠ 判断能否承受（`ruin-first`）≠ 计算期望值（`expected-value`）。
- 业绩是被挑出来的（`survivorship-audit`）和业绩本身藏雷（本卡）可以同时成立，需分别检查。
