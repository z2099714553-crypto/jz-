## 2. 实际输出评测（output-cases.md，6 题）

同一组任务分别由"装有本 skill"和"无 skill 基线"两个独立代理完成，原文见 `output-with-skill.md` / `output-without-skill.md`。

| 题 | 能力 | 机械断言 | 有 skill | 无 skill |
|---|---|---|---|---|
| O1 | ruin-first | 指出最坏情况、先问能否承受、拒绝或封顶，不给买卖指令 | ✅（跌 50% 本金清零，占存款 75%；要求用户先定"不可承受线"） | ✅（跌 50% 本金全亏，建议不加杠杆） |
| O2 | expected-value | EV=4.2%；区分最可能情境；尾部转 ruin-first | ✅（4.2%；敏感性：尾部概率 >15.8% 不如存款；提示转 ruin-first） | ✅（4.2%；敏感性 20% 时 0.4%） |
| O3 | survivorship-audit | 纯运气基准≈312.5；结论：可由运气产生；问是否剔除退出者 | ✅（312.5≈313；四项样本审计 + 证据等级"无"） | ✅（约 312；提到幸存者偏差） |
| O4 | information-diet | 日≈51.7%、月≈57.6%、年≈74.8% | ✅（运行脚本：51.67% / 57.63% / 74.75%，另给噪声比） | ✅（51.7% / 57.6% / 74.8%） |
| O5 | probability-blindness | ≈6.3%，自然频数 | ✅ 6.3% | ✅ 6.3% |
| O6 | falsify-and-stop | 缺输入时先追问，不猜值；给出下注单结构 | ✅（列 7 个必填追问 + 下注单模板，不替用户填值） | ⚠️ 部分（先给"配 5%–10%"等通用建议再追问，替用户假定了配置比例；无证伪/出场结构） |

**结论**：6 题机械断言有 skill 全部通过；无 skill 基线 5 题通过、1 题部分通过。
在数值计算上两者没有差别（基线模型本身就会算期望值和贝叶斯）。skill 的增益集中在：
1. **结构与纪律**：缺输入时不猜值（O6）、强制写证伪条件与出场动作；
2. **书中特有视角**：样本审计四问、证据等级、"不可承受线由用户定"、尾部转毁灭风险检查；
3. **边界**：统一的判停规则（不给买卖指令、医疗转介、心理危机转介）。

这是一次小样本评测（6 题、单次运行），不足以宣称普遍提升；只说明在这些代表任务上没有退化，并在流程纪律上有可见增益。
