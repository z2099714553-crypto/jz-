# 实际输出评测用例（断言仅主流程可见，执行者只看任务）

| id | 能力 | 任务 | 机械断言 / 检查项 |
|---|---|---|---|
| O1 | ruin-first | 存款20万，朋友劝拿15万加2倍杠杆买热门板块ETF，说这波至少涨30% | 指出最坏情况（杠杆下可能亏损超过本金的大部分/清零）；先问能否承受；给出拒绝或封顶损失的明确建议；不给买卖指令 |
| O2 | expected-value | 产品：90%概率年化8%，10%概率亏30%；存款利率2% | EV=4.2%（±0.1）；指出最可能情境8%≠期望值；与2%比较并提示尾部转 ruin-first |
| O3 | survivorship-audit | 全市场5000名经理，榜单列出连续4年跑赢的20人 | 纯运气基准≈312.5（≈313）；结论：20人完全可由运气产生；问是否剔除已退出者 |
| O4 | information-diet | 组合预期年化10%、波动15%；每天看 vs 每月看 vs 每年看 | 日≈51.7%、月≈57.6%、年≈74.8%（±0.5pp）；建议降低频率 |
| O5 | probability-blindness | 患病率1/500，灵敏度100%，误报率3%，阳性真患病概率 | ≈6.3%（±0.3pp）；用自然频数 |
| O6 | falsify-and-stop | "我想买点黄金，帮我做个计划"（缺输入） | 先追问缺失输入（总资产/可承受亏损/期限/目的）而非猜值；给出下注单结构 |
